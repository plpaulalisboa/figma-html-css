CSS - Cascating Style Sheet (Folhas de Estilo em Cascata)

O CSS é responsaável por posicionar os elementos (colocar elementos lado a lado), vai determinar cor, tamanho e fonte.

Tudo o que é relacionado a formatação visual é de responsabilidade do CSS.

Seletor significa que o elemento do HTML eu estou querendo formatar:

seletor { propriedade: valor; }

Tudo isso é uma declaração de CSS.

Entre as chaves é uma regra do CSS.

h1 { color: red; }

Pode ser composta por mais de uma declaração, por exemplo:

h1 { color: red; font-size:16px; }

O CSS pode ter vários arquivos CSS.

A vantagem é que se amanhã você precisar fazer alguma manutenção no estilo do seu site será bem mais fácil.

Quando eu tenho um arquivo CSS externo, eu posso fazer o vínculo em vários arquivos HTML, por exemplo, 50 arquivos HTML, todos eles vão herdar (obedecer) a formatação visual do CSS.

O estilo Inline vai ter uma prioridade quando o seletor for igual.
