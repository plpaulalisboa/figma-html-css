Aula HTML

Anotações sobre as aula de HTML:

O HTML é um arquivo de texto, que contém marcações HTML, por exemplo, título, subtítulo, paragráfo, etc.

  • HTML: é responsável pelo Conteúdodas nossas páginas.
  • CSS: é responsável pelas partes Visuais das nossas páginas.
  • JavaScrip: é responsável pela Interação das nossas páginas.

O Word não cria texto puro, pois tem outros elementos. Já o Bloco de Notas cria texto puro.

Editor de código, por exemplo, o Visual Code vai criar os arquivos Html. Para ler esses arquivos são necessários os Browsers, por exemplo, Google Chrome, Internet Explorer, Opera, etc.

Página na Web é um arquivo HTML. O site é uma pasta, um diretório com vários arquivos HTML lá dentro.

Para funcionar precisa de:

  • URL: Localizador de recursos. É um endereço de um arquivo. Esse endereço precisa ser único.
  • HTTP: Protocolo de transferência de hipertexto. É uma comunicação entre máquina diferentes, por exemplo, Windowns e Linux, usnado uma maneira única de se comunicar.
  • HTML: Ligação de marcação de hipertexto. Não é uma linguagem de programação, pois não tem lógica de programação. Existe marcação (título, imagem, textos e etc).

Tag HTML é uma etiqueta. Marcar um conteúdo e dar um siginificado ao conteúdo.

Usando o "!" e pressionando o Enter, o Visual preenche toda a estrutura inicial para a gente trabalhar com nossos arquivos HTML.
